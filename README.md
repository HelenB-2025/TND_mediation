#Mediation Analysis Using the Test-Negative Design Data

This repository contains R code for implementing the proposed causal mediation analysis methods using the test-negative design (TND) data to evaluate vaccine effectiveness against post-infection outcomes.

## Repository Contents

- **`Implementation`**: Contains functions for implementing the proposed estimation methods and statistical inference using manipulated data.
[Important]: The input data for the function must be manipulated according to the requirements specified at the beginning of the script.

- **`simulation_data generation+estimation`**: Contains the code for conducting simulation studies, including two functions: one for generating simulated data and the other for obtaining mediation effect estimates from the simulated data.

## Usage
All code is written in R. Install the required packages specified in the corresponding scripts before running the analyses.
